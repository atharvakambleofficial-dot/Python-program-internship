# Guess & Count 🎯📊

A terminal number-guessing game plus a word-frequency tool, in one Python file.

## How to run
```
python guess_and_count.py
```

## Scoring rule
You get up to 10 valid attempts per round. Winning on attempt 1 scores
100 points, and each extra attempt costs 10 points (100, 90, 80 ... 10).
Running out of attempts scores 0. Invalid input does not use an attempt.
Round scores add up into a session total.

## Note on common words
Words like "the", "and" and "is" dominate the raw frequency list. An
optional filter hides them so the meaningful words show up.
